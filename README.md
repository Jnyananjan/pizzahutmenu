## 🧠 Concept

This isn’t just a menu.
It’s a **real-world deployed digital experience** designed to replace traditional restaurant menus with a fast, clean, and scalable solution.

Built with **performance + simplicity in mind**, especially for clients who don’t want complex backend systems.

## 🏗️ Architecture

```bash
app/            → Routing & pages (Next.js App Router)
components/     → UI building blocks
hooks/          → Custom logic handlers
lib/            → Helper utilities
public/         → Static images (client-friendly approach)
styles/         → Global styling
```

---

## 🖼️ Why Images Are Stored Locally

Instead of using cloud storage (like Firebase/Supabase), this project uses:

📁 `/public` folder for all images

### 💬 Reason:

This was a **client-driven decision**, finalized after consultation.

✔ No signups required
✔ No API complexity
✔ Faster loading
✔ Easier maintenance for non-tech users
